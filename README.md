### Selected work

- **[Atractor](https://atractor.ai)** — an applied AI lab building text and
  voice agents, evaluation pipelines, and intelligent systems.
- **[YunoAI](https://yunoai.com)** — an intellectual sparring partner designed
  to challenge assumptions instead of validating them.
- **[RecallWeaver](https://github.com/JackCloudman/RecallWeaver)** — persistent
  graph memory for conversational AI, with semantic retrieval, consolidation,
  and an evolving self-model.
- **[jkernel](https://github.com/JackCloudman/jkernel)** — a minimal
  experimental `no_std` kernel written in Rust.
- **[neuralrs](https://github.com/JackCloudman/neuralrs)** — a neural network
  built from scratch in Rust to learn XOR through backpropagation.
